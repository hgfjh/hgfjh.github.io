# Academic Site — Commit 1

A minimal Rust + Askama static-site exporter. There is no runtime web server.

## Build (PowerShell)

```powershell
cargo run
```

This writes `dist/index.html` and `dist/static/style.css`.

## Preview (PowerShell, separate terminal)

```powershell
python -m http.server 8000 --directory dist
```

Open http://localhost:8000/ in your browser. If Windows only provides `py`, use
`py -m http.server 8000 --directory dist` instead.

## Validate

```powershell
cargo fmt --check
cargo clippy -- -D warnings
```

The `Cargo.lock` file is generated by Cargo and should be committed for this application.
Deployment is reserved for Commit 2.

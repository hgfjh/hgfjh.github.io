# Academic Site

A static academic homepage generated by Rust and Askama, hosted on GitHub Pages.
Rust runs at build time only. Visitors receive HTML, CSS, a local WebP portrait,
a small optional video script, and the public CV when requested.

## Design and portrait

The design uses a compact midnight-blue masthead, ordinary links, and numbered
research entries. The selected IMG_7084 hybrid retouch is copied unchanged into
`static/images/portrait.webp` (750 × 1000). Only the optimized public image is
needed in the repository; keep the original and lossless master privately.

The portrait is loaded immediately with intrinsic dimensions to reserve space.
The small genus-two illustration is still a static schematic. `#surface-mount`
is reserved for homepage integration in Commit 8.4. No graphics library is
loaded by the homepage.

## Genus-two mesh (Commit 8.2)

The Rust exporter constructs and checks a triangulation of the double of a
planar pair of pants, including edge orientation and circular vertex links.
It writes `dist/static/meshes/genus2.json`; the current homepage does not
request this asset. See [the construction and proof](docs/genus-two.md).
No new dependencies are required. The optional Python reference check is
`python docs/check_genus_two.py`; it does not replace the Rust tests.

## Standalone surface renderer (Commit 8.3)

The exporter also writes `dist/static/meshes/genus2.bin` and
`dist/static/surface.js`. The binary is 221,152 bytes at the current resolution,
including its 16-byte header. It retains every triangle and converts positions
and normals to f32 for rendering only. See [the renderer notes](docs/surface-renderer.md).

To preview locally after running the exporter:

```powershell
Copy-Item docs/surface-preview.html dist/surface-preview.html
python -m http.server 8000 --directory dist
```

Open http://localhost:8000/surface-preview.html. The preview is intentionally
not copied by the exporter, so a fresh CI build does not publish the preview
page. The homepage remains unchanged until Commit 8.4.

## CoxeterViewer5D

The academic homepage links directly to the independently deployed
[CoxeterViewer5D browser application](https://hgfjh.github.io/CoxeterViewer5D/).
Browser-supported operations require no installation. Native operations and
external research computations require the desktop or CLI workflows described
in the [CoxeterViewer5D documentation](https://github.com/hgfjh/CoxeterViewer5D).
The homepage loads no viewer assets, so the link adds no runtime dependencies
or startup overhead.

## Check and preview (PowerShell)

```powershell
cargo fmt --all -- --check
cargo clippy --all-targets --locked -- -D warnings
cargo test --locked
cargo run --release --locked
python -m http.server 8000 --directory dist
```

Open http://localhost:8000/ and check the portrait, advisor link, research,
CV, software link and mobile layout. The exporter copies the portrait to
`dist/static/images/portrait.webp`; CI checks that the copy matches the source.
If the browser is displaying an older stylesheet or photo, refresh the page.

## Editing content

Use `src/content.rs` for profile information, papers and talks. For each paper,
optional resources are `None` until ready; change to `Some("...")`:

- `abstract_text`: approved plain-text abstract.
- `pdf_url`: approved public manuscript/DOI/arXiv URL; update status as well.
- `youtube_id`: actual 11-character YouTube video ID, with embedding enabled.
- `transcript_url`: public transcript URL.

The existing `static/videos.js` creates the privacy-enhanced YouTube iframe
only on activation. The ordinary YouTube link works without JavaScript.
Do not commit the private manuscripts or the original unredacted CV.

## Publish

The GitHub Actions workflow checks, exports, and deploys the site to GitHub
Pages on pushes to `main`.
